# Terminal Cinema

Search for a movie or TV show on streaming services.

## Requirements

- Python 3

## Run

Clone the repository, then run:

```bash
git clone https://github.com/tylerjohnblakeney-ops/terminal-cinema.git
cd terminal-cinema
python3 cinema.py
```

On Windows, use `python cinema.py` if `python3` isn't recognized.

The program prints search links; it doesn't host or play films. Availability depends on the service and your region.
